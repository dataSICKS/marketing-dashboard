---
name: LTV table requirements
description: User intent for grouping the LTV table and opt-in/opt-out terminology.
---

LTVの表は、商品などの内訳ごとに独立したブロックで表示し、内訳の項目を選択可能にする。

各ブロックの表は、横に期間、縦に項目を配置する。

**Why:** ユーザーが「表は横に期間、縦に項目を置いてほしい！」と指定した。

**How to apply:** 内訳ブロックを維持し、月を列、件数・LTV指標を行にする。

**Why:** ユーザーが「表は内訳の商品ごとにブロックを分けて表示するようにしたい。また、その内訳の項目をオプトインの有り無しとか選択できるようにして」と依頼した。

**How to apply:** この依頼中の「オプトイン有無」は、ユーザーの確認により既存の「オプトアウト有無」を意味する。新しいオプトイン属性の追加要求として扱わない。

月別表示と指定期間の合算表示を切り替えられるようにする。

**Why:** ユーザーは「件数が少ない時に一定期間まとめて見る」ために、月別と指定期間の合算の切り替えを希望した。

**How to apply:** 内訳と絞り込み条件は切り替えても維持する。合算は件数を合計し、LTVは元の定期購入全件から平均を算出する。月別平均の単純平均や、丸め済みの平均からの再計算では件数の偏りと丸め誤差が入る。

LTVページでは初回商品だけの構成比と、2回目以降を含む商品購入比率の両方を確認できるようにする。

**Why:** 集計対象を確認した際、ユーザーが「両方」と回答した。

**How to apply:** 現在の購入記録は最大4回目までなので、全購入履歴や5回目以降を含むと表現しない。購入日はなく初回購入月で対象定期を絞り込む。セット商品をSKUに分解したり、商品順が違うラベルを同一商品と判断するには別途ルールの確認が必要。
